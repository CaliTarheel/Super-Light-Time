# Publication snapshot

Super-Light-Time captures the source used by the Asein Lite coarse burial-speed continuation on 7 October 2026. The engine and web source consist of 230 files, each copied byte for byte from the sealed runtime and independently matched against its prepared source manifest. SOURCE_MANIFEST.json records their hashes and the original source revision. Upstream lineage: https://github.com/CaliTarheel/lite-time. This is a fresh source publication, not a fork of an assumed complete Git history.

The root server is the actual production overlay. It requires externally issued interval tokens, absolute budgets, guardian acknowledgment and an accepted checkpoint chain to evolve. The public copy preserves those checks. Starting its interface does not supply those prerequisites, and a standalone fresh-world launcher is not provided.

Additional files include the existing test suite and small checked-in numerical fixtures, benchmark/reference code, dependency recipes, Windows setup/interface helpers, current coarse and burial regression tests, and selected historical design documents. Historical validation claims concern their original snapshots. This publication does not assert that the entire inherited suite passes against the current overlay.

## Publication-only changes

No sealed engine or browser source was modified. Supplemental source and documentation changes are recorded per file in SOURCE_MANIFEST.json:
- Operational reference copies replace private machine paths and Google Drive destination IDs with explicit placeholders. Bindings, control receipts and history are omitted, and the operational layout is not reconstructed. These are inspection references, not runnable production launchers.
- Three coarse regression tests locate the current root source instead of their former candidate directory. Their physical assertions are unchanged.
- The source PDF's personal Downloads path is omitted from the preserved reference transcription.
- Historical benchmark commands use a relative interpreter path.
- Setup's obsolete instruction to resume a local 40 Myr experiment is removed, and its completion text explains the production requirements.

A historical transition utility in the exact engine snapshot retains its old fixed workspace path. It is not a portable launcher; do not invoke historical migrations against another installation. Generic goSPL WSL paths identify the optional environment, not credentials.

## Exclusions and rights

Generated worlds, accepted checkpoints, saved maps and history, logs, active process state, control/authorization/Watch receipts, account or quota state, credentials, local dependency environments and Git history are not distributed. Small pre-existing numerical test fixtures are retained under tests/fixtures.

No new software license is assigned. This repository preserves the existing source attribution and references; public visibility alone does not grant an open-source license. The production simulation remains a separate installation and was not modified or restarted for this publication.
